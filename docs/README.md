# Documentation

This is the documentation workspace for the new Tangent project. Documents must
state whether they describe a proposal, a decision, an experiment or implemented
behavior. Delivered components include [MIDI import](midi-import.md) and the
[Bevy-core browser piano](piano-player.md).

- [Architecture decision records](adr/README.md)
- [Product and visual design](design/README.md)
- [Sketch index](design/sketches/README.md)
- [Design asset records](design/assets/README.md)
- [Project provenance](../PROVENANCE.md)

Use ADRs for consequential technical choices and design briefs for user-facing
questions. Link the two when a design depends on a technical decision. Large
implementation details belong in their own focused documents, not in the README.

Dates use `YYYY-MM-DD`. Use relative links so the documentation can be read on
GitHub without a documentation server. No docs framework is required yet.
