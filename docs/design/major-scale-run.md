# Major Scale Run (S03)

Train → Major Scale Run teaches a one-octave major scale up and back down.
Choose Right C, Left C or 12 keys; the last level traverses C/G/D/A/E/B/F#/Db/Ab/
Eb/Bb/F, with a right/left/alternating-hand selector. Every note has an explicit spelling and
suggested finger. MIDI cannot establish which hand or finger was used.

The marker waits for the exact pitch/register and full release. Fifteen accepted
steps form one scored task. Twelve tasks finish a session. A wrong attack gives
40 points after correction; first try gives 100; Hint/Hear or Skip gives zero.
An error or assistance early in the scale affects the whole task. Pause preserves
the in-session cursor; retry starts a fresh scale with the recorded level.

Small screens show eight notes at a time with the top note shared between the
ascending and descending windows. Finish, level, hint, Hear and Skip remain on the
same Bevy surface. Existing theme, piano, input and reduced-motion controls apply.

This variant assesses pitch/order only. It does not assess legato, finger technique,
rhythm or evenness. Multiple octaves, metronome and both hands together remain
catalogue extensions. See [ADR-0030](../adr/0030-major-scale-run.md).
